## Défis Rencontrés

### Complexité des Graphes

Les graphes peuvent devenir très complexes avec beaucoup de nœuds et de connexions.

**Solution:** Regroupement logique, simplification pour visualisation

### Performance de l'Analyse

Analyser les patterns sur de nombreux runs peut être coûteux.

**Solution:** Agrégation, cache des résultats

### Format d'Export

Choisir les formats d'export appropriés (JSON, Graphviz) a nécessité des itérations.

**Solution:** Support multiple formats, extensible

---

## Apprentissages

1. **Structure de données:** Une bonne structure de données facilite l'analyse
2. **Performance:** L'agrégation est cruciale pour les analyses sur gros volumes
3. **Visualisation:** Préparer les données pour la visualisation est une étape importante
