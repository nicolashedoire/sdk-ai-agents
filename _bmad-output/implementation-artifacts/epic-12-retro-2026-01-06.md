## Défis Rencontrés

### Différences SQL

SQLite et PostgreSQL ont des syntaxes différentes, notamment pour JSON.

**Solution:** Couche d'abstraction avec génération SQL adaptée

### Performance

Les requêtes sur de gros volumes peuvent être lentes sans indexation.

**Solution:** Indexation stratégique, requêtes optimisées

### Migration des Données

Migrer les données existantes du FileEventStore vers SQL a nécessité un script dédié.

**Solution:** Script de migration avec validation

## Apprentissages

1. **Abstraction SQL:** Une bonne abstraction permet de supporter plusieurs backends
2. **Indexation:** L'indexation est cruciale pour les performances
3. **JSONB:** PostgreSQL JSONB est très performant pour les données JSON
4. **Migration:** Les migrations de données nécessitent une attention particulière
