## Challenges Encountered

### SQL Differences

SQLite and PostgreSQL have different syntaxes, particularly for JSON.

**Solution:** Abstraction layer with adapted SQL generation

### Performance

Queries on large volumes can be slow without indexing.

**Solution:** Strategic indexing, optimized queries

### Data Migration

Migrating existing data from FileEventStore to SQL required a dedicated script.

**Solution:** Migration script with validation

---

## Learnings

1. **SQL Abstraction:** A good abstraction makes it possible to support multiple backends
2. **Indexing:** Indexing is crucial for performance
3. **JSONB:** PostgreSQL JSONB is very performant for JSON data
4. **Migration:** Data migrations require particular attention
