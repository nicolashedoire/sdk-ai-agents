**NFR4:** No untraceable action

**NFR6:** Replay = same logical sequence
**NFR7:** Same tool calls in the same order
**NFR8:** Event log = source of truth (no "hidden" logic)
**NFR9:** Everything is traceable and replayable
**NFR10:** "Deny by default" security - everything must be explicitly authorized
**NFR11:** Security by impossibility, not by configuration
**NFR12:** Stable and minimalist API
**NFR13:** Type-safe, documented, predictable

**NFR19:** Node.js 20+ (LTS)
**NFR20:** ESM and CommonJS support
**NFR21:** Complete type-safety across the whole API
**NFR22:** Package published on the npm registry
**NFR23:** Strict semantic versioning

### Additional Requirements

**From Technical Architecture Considerations:**
- TypeScript/Node.js exclusive for MVP (multi-language support post-MVP)
- Clear, typed API with complete type-safety
- Strong conceptual documentation (mental model first and foremost)
- Real, demonstrative examples (3 mandatory examples)
- Replay as a central feature (the MVP's killer feature)
- Minimal event schema, 1 simple projection, no DSL
- In-memory / file (simple) event store for MVP
- No premature optimization
- Event-sourcing must be invisible on the user side

**From Non-Negotiable Principles:**
- Principle #1: Every action is an event
- Principle #2: No action without a policy
- Principle #3: The LLM never causes a side effect
- Principle #4: Replay must be possible without the LLM
- Principle #5: Security is deny-by-default

**From MVP Strategy:**
- Problem-Solving MVP with a Platform architecture
- Focus on validating the paradigm before extending it
- Ultra-short Quick Start (< 30 minutes)
- Simple API despite a complex core

**Starter Template Requirements:**
- Greenfield project - new project
- Quick Start template with a functional minimal example
- 1 complete example (agent + tool + replay)
