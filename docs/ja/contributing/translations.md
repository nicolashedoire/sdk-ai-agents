# ドキュメントの翻訳

このドキュメントは英語で書かれ、10 の言語に翻訳されています。フランス語、スペイン語、ドイツ語、簡体字中国語、ブラジルポルトガル語、日本語、韓国語、ロシア語、アラビア語、ヒンディー語です。どのページでも、上部にある言語メニューで言語を切り替えられます。

::: tip やさしく言うと
基準は英語です。ほかのすべての言語は英語のページのコピーで、テキストだけが翻訳され、それ以外のもの、つまりコード、リンク、表、見出しのアンカーはすべてそのまま保たれます。CI が実行するチェックは、翻訳を置き去りにする変更を受け付けません。
:::

## どこに何があるか {#where-things-are}

| 何 | どこ |
| --- | --- |
| 英語のページ | `docs/guide/`, `docs/reference/`, `docs/contributing/`, `docs/index.md` |
| 翻訳 | `docs/<code>/` の下にある同じファイル。たとえば `docs/fr/guide/memory.md` |
| メニュー、ボタン、検索のテキスト | `docs/.vitepress/i18n/<code>.ts`。`i18n/en.ts` から翻訳する |
| 言語とサイドバー | `docs/.vitepress/i18n/structure.ts` |
| チェック | `docs/.vitepress/check-translations.ts`。`npm run docs:check` で実行する |

## 翻訳のルール {#the-rules-of-a-translation}

1. **テキストを翻訳し、それ以外はそのまま保つ。** コードブロックは、コメントも含めて英語と同一のままにします。そうすれば、読者はどの言語で読んでいても同じコードをコピーできます。オプション名、関数名、イベントの種類、`committed` のような値は決して翻訳しません。
2. **すべての見出しで英語のアンカーを保つ。** ほかのページは、アンカーを使ってセクションにリンクしています（`./memory#statuses`）。翻訳した見出しの末尾には、英語のアンカーを付けます。

   ```md
   ## Statuts {#statuses}
   ```

3. **リンクを保つ。** 同じリンクを、同じページに向けて、同じフォルダーの中で使います。ホームページでは、フロントマターのリンクに言語のプレフィックスが付きます（`/fr/guide/introduction`）。
4. **構造を保つ。** 表と表の行の数、コールアウトボックス（`::: tip`）、画像を英語と同じにします。
5. **図は翻訳してよい。** Mermaid の図では、ラベルだけを翻訳し、ノード名と矢印はそのまま保ちます。ラベルに括弧、カンマ、その他の句読点が含まれる場合は、引用符で囲みます：`A["Tests (réels)"]`。
6. **一つひとつを説明する。** 翻訳もまた、その分野を知らない人に向けて書くものです。まずはやさしい言葉で、英語のページと同じ説明をします。

## 翻訳をチェックする {#check-a-translation}

```sh
npm run docs:check          # every language
npm run docs:check -- fr    # one language
npm run docs:build          # then build the site
```

`docs:check` は、言語とページごとに次のものを報告します。欠けているページや余分なページ、英語と異なるコード、正しいアンカーのない見出し、欠けているリンクや余分なリンク、存在しないページへのリンク、英語と異なる表やコールアウトボックス、有効な Mermaid ではない図、そしてまだ英語のままの本文やインターフェースのテキストです。CI は、すべてのプルリクエストでこのチェックを実行します。

## 英語のページを変更するとき {#when-you-change-an-english-page}

すべての言語が追いつくまで、CI は失敗します。言い回しを変えた場合は、各言語の同じ箇所を更新してください。新しいコード、新しい見出し、新しいリンクを加えた場合は、どのページのどの行を更新すればよいかを、チェックが教えてくれます。

## 言語を追加する {#add-a-language}

1. `docs/.vitepress/i18n/structure.ts` の `LANGUAGES` に言語を追加します。その言語のコード、[BCP 47](https://www.rfc-editor.org/info/bcp47) のタグ、その言語自身での名前を指定し、右から左に書く言語であれば `dir: 'rtl'` も指定します。
2. `i18n/en.ts` を `i18n/<code>.ts` にコピーしてテキストを翻訳し、`docs/.vitepress/config.mts` でインポートします。
3. すべてのページを翻訳して `docs/<code>/` に置き、`npm run docs:check -- <code>` を実行します。

## 限界 {#limits}

- **イラスト**（SVG 画像）は、どの言語でも英語のままです。
- **検索** は、言語ごとに別々にインデックスを作ります。中国語と日本語では、単語の間にスペースを入れる言語と比べて、検索が単語全体にうまく一致しないことがあります。
- **品質。** 翻訳は AI モデルが書き、CI が英語の構造と照らし合わせてチェックしたものです。各言語のネイティブスピーカーによる校正は受けていません。修正は大歓迎です。各ページの下部にある「GitHub でこのページを編集する」を使ってください。
