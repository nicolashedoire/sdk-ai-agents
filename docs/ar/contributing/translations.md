# ترجمة التوثيق

التوثيق مكتوب بالإنجليزية ومترجم إلى عشر لغات: الفرنسية، والإسبانية، والألمانية، والصينية المبسّطة، والبرتغالية البرازيلية، واليابانية، والكورية، والروسية، والعربية، والهندية. تتيح قائمة اللغات في أعلى كل صفحة التبديل بينها.

::: tip بكلمات بسيطة
الإنجليزية هي المرجع. كل لغة أخرى نسخة من الصفحات الإنجليزية مع ترجمة النص والإبقاء على كل ما عداه مطابقًا: الشيفرة، والروابط، والجداول، ومراسي العناوين. ويرفض فحصٌ يشغّله نظام التكامل المستمر (CI) أي تغيير يترك ترجمة متأخرة.
:::

## أين توجد الأشياء {#where-things-are}

| ماذا | أين |
| --- | --- |
| الصفحات الإنجليزية | `docs/guide/`، `docs/reference/`، `docs/contributing/`، `docs/index.md` |
| ترجمة | الملفات نفسها تحت `docs/<code>/`، مثلًا `docs/fr/guide/memory.md` |
| القوائم، والأزرار، ونصوص البحث | `docs/.vitepress/i18n/<code>.ts`، مترجمة من `i18n/en.ts` |
| اللغات والشريط الجانبي | `docs/.vitepress/i18n/structure.ts` |
| الفحص | `docs/.vitepress/check-translations.ts`، يُشغَّل بـ `npm run docs:check` |

## قواعد الترجمة {#the-rules-of-a-translation}

1. **ترجم النص، وأبقِ الباقي.** تبقى كتل الشيفرة مطابقة للإنجليزية، بما فيها التعليقات، حتى يستطيع القارئ نسخ الشيفرة نفسها أيًا كانت اللغة. ولا تُترجَم أبدًا أسماء الخيارات، وأسماء الدوال، وأنواع الأحداث، والقيم مثل `committed`.
2. **أبقِ المرساة الإنجليزية لكل عنوان.** تشير صفحات أخرى إلى الأقسام بمراسيها (`./memory#statuses`). ينتهي العنوان المترجَم بالمرساة الإنجليزية:

   ```md
   ## Statuts {#statuses}
   ```

3. **أبقِ الروابط.** الروابط نفسها، إلى الصفحات نفسها، في المجلد نفسه. في الصفحة الرئيسية، تحصل الروابط الموجودة في الترويسة الأمامية (front matter) على بادئة اللغة (`/fr/guide/introduction`).
4. **أبقِ البنية.** العدد نفسه من الجداول ومن صفوف الجداول، وصناديق التنبيه نفسها (`::: tip`)، والصور نفسها.
5. **يمكن ترجمة المخططات.** في مخطط Mermaid، ترجم التسميات فقط؛ وأبقِ أسماء العقد والأسهم. ضع التسمية بين علامتَي اقتباس حين تحتوي على أقواس أو فواصل أو علامات ترقيم أخرى: `A["Tests (réels)"]`.
6. **اشرح كل شيء.** الترجمة مكتوبة لشخص لا يعرف الموضوع هو الآخر: الكلمات البسيطة أولًا، والشروح نفسها الموجودة في الصفحة الإنجليزية.

## فحص الترجمة {#check-a-translation}

```sh
npm run docs:check          # every language
npm run docs:check -- fr    # one language
npm run docs:build          # then build the site
```

يبلّغ `docs:check`، لكل لغة وصفحة، عن: الصفحات الناقصة أو الزائدة، والشيفرة التي تختلف عن الإنجليزية، والعنوان الذي لا يحمل المرساة الصحيحة، والرابط الناقص أو الزائد، والرابط إلى صفحة غير موجودة، والجدول أو صندوق التنبيه المختلف، والمخطط الذي ليس Mermaid صالحًا، والنص أو نصوص الواجهة التي لا تزال بالإنجليزية. ويشغّله نظام التكامل المستمر على كل طلب سحب (pull request).

## حين تغيّر صفحة إنجليزية {#when-you-change-an-english-page}

يفشل نظام التكامل المستمر إلى أن تلحق كل اللغات بالتغيير. لتغيير في الصياغة، حدّث المقطع نفسه في كل لغة. ولشيفرة جديدة، أو عنوان جديد، أو رابط جديد، يخبرك الفحص بالصفحات والأسطر التي يجب تحديثها.

## إضافة لغة {#add-a-language}

1. أضفها إلى `LANGUAGES` في `docs/.vitepress/i18n/structure.ts`: رمزها، ووسم [BCP 47](https://www.rfc-editor.org/info/bcp47) الخاص بها، واسمها بلغتها، و`dir: 'rtl'` للغة تُكتَب من اليمين إلى اليسار.
2. انسخ `i18n/en.ts` إلى `i18n/<code>.ts`، وترجم النصوص، واستوردها في `docs/.vitepress/config.mts`.
3. ترجم كل صفحة إلى `docs/<code>/`، ثم شغّل `npm run docs:check -- <code>`.

## الحدود {#limits}

- **الرسوم التوضيحية** (صور SVG) بالإنجليزية في كل اللغات.
- **البحث** يفهرس كل لغة على حدة؛ وفي الصينية واليابانية، يطابق البحث الكلمات الكاملة على نحو أضعف مما في اللغات التي تفصل بين كلماتها مسافات.
- **الجودة.** كتب الترجمات نموذج ذكاء اصطناعي، وتحقّق نظام التكامل المستمر من مطابقتها للبنية الإنجليزية، ولم يراجعها متحدّثون أصليون لكل لغة. التصحيحات مرحّب بها: استخدم «عدّل هذه الصفحة على GitHub» في أسفل كل صفحة.
