## От промпта к решению, которое можно проверить {#from-a-prompt-to-a-decision-you-can-audit}

Классический вызов LLM ведёт прямо от вопроса к ответу. Когнитивный агент строит явную картину задачи, исследует несколько вариантов, испытывает их на прочность, проверяет факты с помощью управляемых инструментов и только затем принимает решение — а каждый шаг вы можете прочитать потом.

```ts
import { createSDK } from '@sdk-ai-agents/core';

const sdk = createSDK({ apiKey: process.env.OPENAI_API_KEY, jev: { apiKey: process.env.TYPESAFE_API_KEY } });

const lookupMetric = sdk.defineTool({ /* name, description, zod schema, handler */ });
const analyst = sdk.createCognitiveAgent({ name: 'analyst', model: 'gpt-4o', tools: [lookupMetric] });
const { answer, decision, state, runId } = await analyst.think({
  problem: 'Should we build or buy our analytics module?',
});

console.log(answer);                          // the decision, in plain words
console.log(state.hypotheses);                // every option considered, with its support
console.log(await sdk.getRunCost(runId));     // what it cost, per model
```

## Один SDK, все уровни {#one-sdk-every-layer}

![Архитектура SDK](/images/architecture.svg){.illustration}

| Вам нужно | Обычный API LLM | SDK AI Agents |
| --- | --- | --- |
| Рассуждать, прежде чем отвечать | Генерация за один проход | Гипотезы, симуляция и критика над явным состоянием |
| Рассуждать как конкретный человек | Длинный системный промпт | Версионируемый профиль мыслителя, уточняемый по обратной связи |
| Быстрые откалиброванные решения | Разбор свободного текста | Типизированные ответы с вероятностями и уверенностью (Jev) |
| Подключить инструменты компании | Отдельная «склейка» для каждого инструмента | Сервер и клиент MCP под управлением политик |
| Знать, что произошло | Логи, если они есть | Журнал событий, воспроизведение, восстановление ментального состояния |
| Контролировать риски и расходы | Надежда | Политики, одобрения, бюджеты, затраты по запуску, оповещения об инцидентах |
