# Затраты на API

SDK записывает расход токенов каждого вызова модели **в том запуске, который его сделал**, — выбор инструмента, когнитивные мысли и типизированные решения — и оценивает его стоимость по каждой модели.

```ts
const cost = await sdk.getRunCost(runId);
```

```json
{
  "runId": "run_7f3…",
  "currency": "USD",
  "totalUsd": 0.01842,
  "complete": true,
  "unpricedModels": [],
  "lines": [
    { "model": "gpt-4o", "source": "llm", "calls": 9, "inputTokens": 14210, "outputTokens": 2310, "costUsd": 0.0186 },
    { "model": "jev-1.13.0", "source": "decision", "calls": 7, "inputTokens": 5880, "outputTokens": 140, "costUsd": 0.00025 }
  ]
}
```

## Цены {#prices}

Цены на LLM часто меняются и зависят от вашего договора, поэтому они являются **конфигурацией, а не кодом**. По умолчанию поставляются только цены, сверенные с документацией поставщиков, — сегодня это Jev ($0,042 за миллион входных токенов, выходные бесплатно, проверено 2026-09-23), как под его идентификаторами TypeSafe (`jev-*`), так и через Vercel AI Gateway (`typesafe-ai/jev`).

```ts
const sdk = createSDK({
  apiKey,
  pricing: {
    // Illustrative values: use your provider's current prices or your contract.
    'gpt-4o': { inputPerMillion: 2.5, outputPerMillion: 10 },
    'gpt-4o-mini': { inputPerMillion: 0.15, outputPerMillion: 0.6 },
  },
});
```

Ключи — это точные идентификаторы моделей или префиксы, заканчивающиеся на `*`. Провайдеры часто отвечают идентификатором с версией (`gpt-4o-2024-08-06`), хотя вы запрашивали `gpt-4o`: SDK записывает оба и сначала ищет возвращённый идентификатор, затем запрошенное имя — точные ключи раньше префиксов, а среди префиксов выигрывает самый длинный. Будьте осторожны с префиксами: `gpt-4o*` соответствует и `gpt-4o-mini`, если нет `gpt-4o-mini*`.

Модель без цены всё равно учитывается (вызовы и токены) и указывается в `unpricedModels`, а отчёт помечается как `complete: false` — SDK никогда не придумывает цену.

## Откуда берётся расход {#where-usage-comes-from}

| Событие | Источник | Поля |
| --- | --- | --- |
| `intention.generated` | Встроенное рассуждение, выбор инструмента | `model`, `requestedModel`, `usage.promptTokens`, `usage.completionTokens` |
| `cognition.thought` | Когнитивные операции, включая исправления и неудачные попытки | `model`, `requestedModel`, `usage.calls` |
| `decision.evaluated` | Jev и другие бэкенды типизированных решений | `model`, `usage.inputTokens`, `usage.outputTokens` |

Поскольку расход хранится в событиях, вы можете и сами вычислять затраты с помощью `computeRunCost(runId, events, pricing)`, агрегировать их по агенту или по дню или передавать в свою систему биллинга.

## Бюджеты {#budgets}

Стоимость — лишь одна сторона; политики также могут ограничивать **шаги, токены и вызовы инструментов** по агенту, инструменту и периоду — см. [Управляемые агенты](./governed-agents). У когнитивных агентов есть собственные лимиты (`maxSteps`, `maxToolCalls`, `timeoutMs`). `budgetLimit` с `maxCost` ограничивает сумму в долларах, которую вызовы модели агента тратят за период, по ценам выше; если у модели нет цены, ограничение нельзя проверить, и вызовы инструментов отклоняются.
