# Обзор проекта

**Тип:** библиотека (SDK на TypeScript)
**Архитектура:** event sourcing с разделением ответственности

## Краткое изложение {#executive-summary}

SDK_AI_Agents — это инфраструктура управления ИИ-агентами со встроенным event sourcing, воспроизведением и безопасностью, заложенной в архитектуру. SDK превращает ИИ-агентов из экспериментальных инструментов в управляемые, объяснимые системы принятия решений, готовые к продакшену.

## Классификация проекта {#project-classification}

- **Тип репозитория:** монолит (единая связная кодовая база)
- **Тип проекта:** библиотека (SDK на TypeScript)
- **Основной язык:** TypeScript 5.x
- **Архитектурный шаблон:** event sourcing с разделением ответственности (движок рассуждения ≠ движок действий)

## Ключевые возможности {#key-features}

### Основные возможности {#core-capabilities}

1. **Встроенный event sourcing**
   - Все события сохраняются в хранилище событий
   - Детерминированное воспроизведение без вызова LLM
   - Полная прослеживаемость каждого решения

2. **Разделение рассуждения и действия**
   - Движок рассуждения: генерирует намерения (без побочных эффектов)
   - Движок действий: выполняет намерения после проверки
   - Безопасность, заложенная в архитектуру: LLM никогда не вызывает побочный эффект напрямую

3. **Встроенное управление**
   - Движок политик: проверяет намерения перед выполнением
   - Трекер бюджета: отслеживает затраты и расход по агенту, инструменту и периоду
   - Менеджер одобрений: процесс одобрения человеком для критичных действий
   - Журнал аудита: полная прослеживаемость решений политик

4. **Несколько провайдеров LLM**
   - Абстракция LLMProvider для OpenAI и Anthropic
   - Автоматическое переключение между провайдерами
   - Конфигурация для каждого провайдера (temperature, maxTokens)

5. **Когнитивная наблюдаемость**
   - Граф рассуждения: визуализация процесса рассуждения
   - Анализ альтернатив: альтернативы, которые рассматривал агент
   - Закономерности решений: закономерности решений в нескольких запусках
   - Визуализация трасс: подготовка трасс к визуализации

6. **Тестирование и контроль качества**
   - Эталонные трассы: эталонные трассы для тестирования
   - Обнаружение регрессий: автоматическое обнаружение регрессий
   - Проверки: проверки поведения на трассах
   - Интеграция с CI/CD: экспорт результатов тестов (JUnit XML, JSON)

7. **Расширенная наблюдаемость**
   - Сравнение запусков: сравнение двух выполнений
   - Анализ влияния: анализ влияния до и после развёртывания
   - Расширенная фильтрация событий: фильтрация событий по путям JSON

## Основные черты архитектуры {#architecture-highlights}

### Абстракция хранилища событий {#event-store-abstraction}

- **IEventStore**: общий интерфейс для всех хранилищ событий
- **FileEventStore**: реализация на файлах (MVP)
- **SQLEventStore**: обобщённая реализация на SQL
- **SQLiteEventStore**: реализация на SQLite
- **PostgreSQLEventStore**: реализация на PostgreSQL с JSONB

### Архитектура движков {#engine-architecture}

- **ReasoningEngine**: генерирует намерения из LLM
- **ActionEngine**: выполняет намерения после проверки
- **PolicyEngine**: проверяет намерения по политикам
- **ReplayEngine**: воспроизводит выполнения по событиям

### Система реестров {#registry-system}

- **ToolRegistry**: управляет доступными инструментами
- **CapabilityRegistry**: управляет возможностями (группами инструментов)

### Система менеджеров {#manager-system}

- **ApprovalManager**: управление одобрениями человеком
- **BudgetTracker**: отслеживание бюджета и расхода
- **GoldenTraceManager**: управление эталонными трассами
- **RegressionTestManager**: управление наборами регрессионных тестов
- **AssertionManager**: управление проверками поведения
- **ImpactAnalysisManager**: управление анализом влияния

## Обзор разработки {#development-overview}

### Предварительные требования {#prerequisites}

- Node.js 20.0.0+ (LTS)
- npm или аналог
- TypeScript 5.3.2+ (установленный локально)

### Начало работы {#getting-started}

```bash
# Installation
npm install

# Build
npm run build

# Tests
npm test

# Watch mode
npm run dev
```

### Основные команды {#key-commands}

- **Установка:** `npm install`
- **Сборка:** `npm run build`
- **Разработка:** `npm run dev` (режим наблюдения)
- **Тесты:** `npm test`
- **Тесты в режиме наблюдения:** `npm run test:watch`
- **Покрытие тестами:** `npm run test:coverage`
- **Линтинг:** `npm run lint`
- **Форматирование:** `npm run format`
- **Проверка:** `npm run check` (линтинг + форматирование)
